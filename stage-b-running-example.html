Stage B: Chunking and Cleaning - Running Example

Stage B takes raw page text from Stage A and produces clean text chunks suitable for NER and extraction. Examples below mirror the actual logic in chunk_text.py.

Example document: Heidenreich, 2022, AHA_ACC_HFSA guidelines.pdf
b
Chunk and clean
In: raw_text (pages) | Out: text_chunks
->
text_chunks
chunk_id, page, source, text, from_table

What Stage B does: Normalizes line breaks, splits text into sentences, builds chunks up to a max character limit, removes artifacts and citations, merges tiny fragments, deduplicates near-duplicates, and adds table rows as sentence-like chunks. Output matches TextChunks and stage_b_text_chunks.json.

Processing steps with output examples

Each step shows a short input and its resulting chunk(s).

1. Normalize newlines
Stage B removes layout artifacts by collapsing multiple newlines, joining mid‑word breaks, and fixing punctuation spacing before sentence tokenization.
Input
"heart fail\nure.\nThe dose\nwas 20 mg."
->
Output
"heart failure. The dose was 20 mg."
2. Sentence-first chunking (max chars)
Sentences are grouped until adding another would exceed the max chunk length (default 400 chars per chunk). No mid‑sentence splits; truncated sentences are merged first.
Input
Sentence 1 (120 chars). Sentence 2 (140 chars). Sentence 3 (180 chars).
->
Output
Chunk A: Sentence 1 + Sentence 2 Chunk B: Sentence 3
3. Citation stripping
Generic citation patterns (lists, ranges, trailing refs) are removed to reduce noise before downstream NER and extraction.
Input
"Therapy is recommended.1-3" or "improves outcomes, 12"
->
Output
"Therapy is recommended." and "improves outcomes"
4. Split multi-statement blocks
Enumerated or multi‑recommendation blocks are split into individual chunks so each chunk expresses a single directive.
Input
"1. Patients should receive ACE inhibitors. 2. Patients should avoid NSAIDs."
->
Output
Chunk A: Patients should receive ACE inhibitors. Chunk B: Patients should avoid NSAIDs.
5. Merge small or truncated chunks
Very short fragments (<60 chars) and mid‑sentence pieces are merged with neighbors when the merged length stays within 550 chars; special cases can use a more flexible 800‑char limit.
Input
Chunk A: "In patients with heart failure" Chunk B: "beta blockers reduce mortality."
->
Output
"In patients with heart failure beta blockers reduce mortality."
6. Table rows to sentence-like chunks
Tables are converted into sentences based on detected table type and marked as from_table for traceability. Real examples from Tests/outputs shown as input → output.

Output
"ACEi is angiotensin-converting enzyme inhibitors"

Output

Each chunk is serialized with identifiers, source metadata, and optional table provenance for later stages.

->
